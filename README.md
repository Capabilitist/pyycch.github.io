# 「空気」のマルチエージェント・シミュレーター (マニュアル・解説)

読書猿氏のブログ記事（ティムール・クランの「虚偽表明モデル（Preference Falsification）」等に基づく）で紹介された「空気の数理モデル」を可視化したマルチエージェント・シミュレーターです。

---

## 1. シミュレーションのモデル構造

各エージェント $i$ は、自身の「本音（私的選好） $x_i$」と「他者の表明の加重平均（空気） $m_i$」の間で葛藤します。

### ① 空気の推定 ($m_i$)
エージェント $i$ は、すでに発言した他者 $j$ の表明 $y_j$ に対し、自身が定めた重み $w_{ij}$（$0 \le w_{ij} \le 1$, $\sum_j w_{ij} = 1$）を用いて加重平均を計算し、現在の「空気 $m_i$」を推定します。

$$m_i = \frac{\sum_{j \in \text{発言者}} w_{ij} y_j}{\sum_{j \in \text{発言者}} w_{ij}}$$

### ② 意思決定（効用関数）
エージェントは以下の2つの選択肢から、手元で算出した損失を最小化（効用を最大化）する行動を選択します：

1. **沈黙する ($y_i = 0$)**:
   - 発言コスト $k_i$ はかかりませんが、本音を発言できない損失が生じます。
   - 損失: $L_{\text{silent}} = x_i^2 + c_i m_i^2$
2. **発言する ($y_i \neq 0$)**:
   - 本音 $x_i$ と空気 $m_i$ のバランスをとった最適な表明 $y_i^* = \frac{x_i + c_i m_i}{1 + c_i}$ を発言します。ただし発言コスト $k_i$ が発生します。
   - 損失: $L_{\text{speak}} = (y_i^* - x_i)^2 + c_i (y_i^* - m_i)^2 + k_i$

## 2. パラメータの解説と変更時の効果

| パラメータ | 説明 | いじった時の効果・現象 |
| :--- | :--- | :--- |
| **エージェント数 ($N$)** | 集団全体の人数 | 人数が多いほど局所的な空気の偏り（クラスタ）が大きくなりやすくなります。 |
| **初期発言者数 ($s$)** | ステップ0で最初に意見を述べる先陣の人数 | **非常に強い影響**を及ぼします。最初の数人の意見が偶発的に偏っていると、集団全体の本音の平均と正反対の「空気」に固定化される現象が発生します。 |
| **同調性 ($c_i$)** | 周囲の空気 $m_i$ への敏感さ（同調圧力の受けやすさ） | 値を大きくすると、周囲に逆らう発言を避け、本音とは異なる建前 $y_i$ を述べるようになります。 |
| **発言コスト ($k_i$)** | 発言することによる摩擦・炎上リスク・手間 | 値を大きくすると、多くのエージェントが発言を回避して「沈黙 ($y_i=0$)」を選択し、**サイレント・マジョリティ（沈黙する多数派）**が形成されます。 |
| **観測可能数 ($Y_i$)** | 空気を察知する際に参照する周囲の人数 | 値を小さくすると狭い情報網に依存することになり、**エコーチェンバー現象**が発生しやすくなります。 |

## 3. 画面表示と色合いの解説

* **ノード（丸印）**: 各エージェントを表します。
  * **中心色 (本音 $x_i$)**: 暖色（赤/ピンク）= 賛成、寒色（水色/青）= 反対、白 = 中立
  * **外周枠 (表明 $y_i$)**: 発言している場合は発言内容の色（賛成/反対）。**黒枠**の場合は沈黙状態（$y_i=0$）を表します。
* **エッジ（結合線）**: 
  * **白色の線**で描画されます。エージェント $i$ が相手 $j$ を重視する重み $w_{ij}$ の大きさに応じて太さが変化します。
* **空気の推移グラフ (折れ線)**:
  * **紫色 (実線)**: 全体空気の平均 ($m_i$)
  * **水色 (破線)**: 平均表明 ($y_i$)
  * **赤色 (薄線)**: 平均本音 ($x_i$)
  * **黄色 (実線・右軸)**: 沈黙率 (%)

## 4. 操作方法

1. **スタート / 一時停止**: シミュレーションの時間を進める / 停止します。
2. **1ステップ進む**: 1時間ステップのみ更新します。
3. **リセット**: パラメータ設定を反映させてステップ0の状態に戻します。
4. **一律設定 / ランダム(範囲)設定**: 
   - 「一律設定」: 全エージェントに同じ $c_i, k_i, Y_i$ を適用します（本音 $x_i$ は個々にランダム生成）。
   - 「ランダム設定」: 各エージェントのパラメータをスライダーで指定した範囲内で個別にランダム生成します。
