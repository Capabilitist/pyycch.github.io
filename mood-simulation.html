モデルの概要と観察のポイント

このシミュレーションは、人々が「自分の本音」と「周囲の空気（他人の表明の加重平均）」の間で葛藤し、発言コストを考慮して表明（賛成/反対/沈黙）を決定するモデルです。

  • 沈黙の螺旋: 同調性 $c_i$ や発言コスト $k_i$ を高くすると、少数派が発言を諦め、本来は拮抗していた本音が一方的な「空気」に支配される現象が起きます。
  • 最初の数人 $s$: 最初に発言する人々の意見が偶発的に偏っていると、集団全体の本音と正反対の空気に固定化されることがあります。

モデルの解説と操作ガイド

1. シミュレーションの背景

読書猿氏のブログ記事（クランの「虚偽表明モデル」等に基づく）で紹介された「空気の数理モデル」を可視化したマルチエージェント・シミュレーターです。

人間社会では、自分の「本音」と集団の「空気（多数派の意見）」が異なるとき、批判を恐れたり同調圧力に屈して「建前」を言ったり、沈黙を守ったりします。このシミュレーターでは、個々のエージェントが相互作用しながらどのような集団ダイナミクスを生むかを実験できます。

2. 数理モデルの仕組み

■ 空気の推測 m_i

エージェント i は、すでに発言した他者 j の表明 y_j に対し、自身が付与した重み w_ij を用いて加重平均を計算し、現在の「空気 m_i」を推定します。

m_i = ( Σ_{j ∈ 発言者} w_ij * y_j ) / ( Σ_{j ∈ 発言者} w_ij )
■ 意思決定と効用関数

エージェントは以下の2つの選択肢から、自身の損失を最小化（効用を最大化）する行動を選びます。

  1. 沈黙する (y_i = 0): 発言コストはゼロですが、本音を発言できない心理的不快感が発生。
  2. 発言する (y_i ≠ 0): 本音 x_i と空気 m_i のバランスをとった最適な表明 y_i* = (x_i + c_i * m_i) / (1 + c_i) を出力。ただし発言コスト k_i が発生。

3. 各パラメータの解説と変更時の効果

N : エージェント数

集団の全体の人数。人数が多いほどネットワークが複雑化し、局所的な空気の形成が起こりやすくなります。

s : 最初に発言する人数

ステップ0で意見を言う先陣。s の人々の意見が偏っていると、その後の集団全体の空気が一気に引きずられます。

x_i : 本音 (-1 ～ +1)

+1が賛成、-1が反対、0が中立。本音の平均を正に設定しても、空気次第で反対が優勢になることがあります。

c_i : 同調性 (空気への敏感さ)

同調性が高いと、空気に逆らう発言を避け、本音とは異なる表明（建前）をするようになります。

k_i : 発言コスト係数

発言に伴うリスクや手間の大きさ。コストを上げると「サイレント・マジョリティ（沈黙する多数派）」が発生します。

Y_i : 観測可能数

空気を知るために参照する他者の数。小さいと狭い情報網（エコーチェンバー）になりやすくなります。

4. 画面の色の意味

  • ノードの中心色（本音 x_i）: 暖色（赤/ピンク）= 賛成、寒色（水色/青）= 反対、白 = 中立(0付近)
  • ノードの外周リング（表明 y_i）: 発言している場合はその色。沈黙（y_i = 0）の場合は黒いリングで表示されます。
  • エッジ（白いリンク線）: エージェント i が相手 j を重視する重み w_ij。線の太さが重みの大きさを表します。
